# 项目部署运行手册(心屿 MindIsle v3.0)

## 1. 环境要求

| 项 | 要求 | 说明 |
|---|---|---|
| 前端 | 任意现代浏览器(Chrome 105+ / Edge / Safari 15.4+ / Firefox 121+) | 纯静态,无需任何环境 |
| 后端(可选) | Node.js ≥ 18(推荐 18/20/22) | 零外部依赖,不需要 npm install |
| 数据库(可选) | Supabase 免费项目 | 不配则自动用本地 JSON 文件 |

## 2. Node.js 版本要求

`node -v` 应输出 ≥ v18.x(v3.0 用了 Node 18+ 的全局 fetch,Windows 自带的旧版不行)。检查方式:

```bash
node -v
```

版本过旧时到 <https://nodejs.org> 下载 LTS 版安装即可。

## 3. 安装依赖步骤

**不需要安装任何依赖。** 前端无框架;后端只用 Node 内置模块(http/crypto/fs)。项目里没有 node_modules,也不需要 `npm install`(package.json 仅为元信息与启动脚本)。

## 4. 前端运行命令

前端是纯静态站,三种打开方式任选:

| 方式 | 步骤 |
|---|---|
| 直接打开 | 双击 `frontend/index.html` |
| 后端托管(推荐) | 先启动后端(见下),浏览器访问 http://127.0.0.1:3001/ |
| 静态服务器 | 任意静态托管(GitHub Pages / Nginx / Vercel),上传 `frontend/` 目录内容 |

## 5. 后端运行命令

```bash
cd server
node index.js
# 看到 "心屿 MindIsle API 已启动 http://localhost:3001 · 存储模式:本地 JSON(mock)" 即成功
```

验证(另开一个终端):

```bash
cd server
node scripts/smoke.js
# 预期输出:冒烟自测结果: 31 通过 / 0 失败(共 31 项)
```

重置演示数据:

```bash
node seed.js
```

## 6. 数据库初始化步骤(可选)

1. 注册并登录 <https://supabase.com>,创建免费项目;
2. 打开 **SQL Editor → New query**;
3. 粘贴 `database/migrate.sql` 全文,点击 Run(脚本幂等,可重复执行);
4. 验证:执行 `SELECT table_name FROM information_schema.tables WHERE table_schema='public' ORDER BY table_name;` 应看到 9 张表;
5. 重启后端并带上环境变量(见下节),即从 mock 模式切换为真实数据库。

## 7. 环境变量配置方法

后端全部环境变量**可选**,不配即纯本地演示模式。两种配置方式:

**方式一:命令行临时设置(Windows PowerShell)**

```powershell
$env:PORT="3001"
$env:SUPABASE_URL="https://xxxx.supabase.co"
$env:SUPABASE_SERVICE_KEY="你的 service_role key"
$env:AI_API_KEY="sk-xxx"
$env:AI_BASE_URL="https://api.deepseek.com/v1"
$env:AI_MODEL="deepseek-chat"
node index.js
```

**方式二:把 `server/.env.example` 复制为 `.env` 并填值**(服务不自动读 .env,需自行 export/set;推荐方式一)

| 变量 | 默认 | 说明 |
|---|---|---|
| PORT | 3001 | 端口 |
| JWT_SECRET | 自动生成(data/secret.txt) | token 签名密钥 |
| SUPABASE_URL | 空 | 配后走 Supabase |
| SUPABASE_SERVICE_KEY | 空 | Supabase service_role key |
| AI_API_KEY | 空 | 配后走真实大模型 |
| AI_BASE_URL | https://api.openai.com/v1 | OpenAI 兼容地址 |
| AI_MODEL | gpt-4o-mini | 模型名 |
| STATIC_DIR | 空 | 静态托管目录;本包前端在 ../frontend,演示托管时设 `../frontend` |

## 8. 常见错误解决方法

| 现象 | 原因 | 解决 |
|---|---|---|
| `EADDRINUSE: address already in use :::3001` | 端口被占用(上次启动的进程还在) | 换端口 `PORT=3017 node index.js`,或结束占用进程 |
| 冒烟测试 `ECONNREFUSED` | 服务没起来,或 Node 把 localhost 解析成 IPv6 而服务只监听 127.0.0.1 | 先确认服务已启动;把冒烟地址固定为 127.0.0.1(smoke.js 已内置) |
| 前端打开是旧界面 | 浏览器缓存 | Ctrl+F5 强刷;新版自带 ?v=3.0.0 版本号 + 页脚版本徽标 |
| Supabase 请求 401/403 | SERVICE_KEY 不对或用了 anon key | 用项目 Settings → API → service_role key |
| AI 接口 401 | AI_API_KEY 无效 | 检查 key 与 AI_BASE_URL;不想配就删掉变量走内置规则回复 |
| Windows PowerShell 里 curl 中文乱码 | 控制台编码 GBK | `$env:PYTHONIOENCODING` 不适用;改用 `Invoke-RestMethod -ContentType "application/json; charset=utf-8"` |
| 数据想重置 | — | mock 模式:删除 `server/data/db.json` 后 `node seed.js`;Supabase 模式:重跑 migrate.sql(幂等) |
