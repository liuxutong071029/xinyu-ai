🖥️ 如何运行与部署

本机预览(前端):双击 index.html,或打开 http://127.0.0.1:3017/(验证服务器)。登录任一演示账号(密码 demo123456)→ 右上角 🎨 切换 12 套风格。

后端(mock 模式,零依赖):cd server → node index.js → 另开终端 node scripts/smoke.js(预期 31 通过/0 失败)。

Supabase(可选):SQL Editor 执行 supabase/migrations/001_init.sql → 配 SUPABASE_URL/SUPABASE_SERVICE_KEY 重启服务即切换真实数据库;真实大模型配 AI_API_KEY(OpenAI 兼容),不配自动用内置规则回复。

GitHub Pages 上线(新旧并存):仓库内新建 v3/ 目录上传本目录 7 个文件(旧文件一个不动)→ 访问 https://<用户名>.github.io/xinyu-ai/v3/。回滚 = 删除 v3/ 目录即可。
