# 心屿 MindIsle v3.0 项目介绍

## 一句话定位

面向心理资源不足地区青少年的 AI 心理陪伴与支持平台 —— 用「学生 ↓ AI 陪伴 ↓ 心理评估 ↓ 数据沉淀 ↓ 成长画像 ↓ 家庭/学校支持」形成完整心理支持闭环。

## 版本历史

| 版本 | 内容 |
|---|---|
| v2.1 | 角色选择分流(学生/普通用户/学校管理员/社区管理员)、信息管理模块、头像、localStorage 持久化 |
| v2.2 | 五角色改版(学生/普通用户/学校管理人员/家长/社区管理人员)、树洞深化、5 个演示账号 |
| v2.3 | 成长档案、学校端四模块、课程库、语音输入(本仓库的基线) |
| **v3.0 焕彩主题版** | **12 套全局主题切换 + 视觉升级 + 缓存修复 + 演示账号同步;后端 API + Supabase 迁移深化;小学阶段零改动** |

## v3.0 新增了什么(相对 v2.3)

1. **12 套全局主题系统**:登录后右上角 🎨 打开风格设置面板,即点即换、刷新保持;首页/成长档案/测评中心/AI 疏导/自助训练/心屿 树洞/课程库/个人中心统一套用同一套视觉。生效范围:初中/高中学生 + 全部演示账号;**小学界面逐字未动**。
2. **视觉升级**:白色方框按钮与生硬描边替换为对应风格圆角/主题色/柔和阴影(基底 = 17 Takram「柔和科技」设计语言)。
3. **缓存修复**:样式与脚本带 `?v=3.0.0` 版本号 + no-cache 头 + 页脚版本徽标,修改后无需手动刷新。
4. **演示账号同步**:5 个演示账号登录即默认「治愈校园」风格(幂等回填,不覆盖用户数据)。
5. **后端 MVP 深化**:零依赖 Node API(注册/登录/资料/AI 创建/AI 聊天/测评/树洞/家庭/统计/行为台账)+ Supabase 迁移脚本(9 表 + 15 条 RLS 四角色权限策略)+ AI 记忆/情绪识别/风险提示(无密钥自动降级内置规则)。
6. **改造纪律**:app.js 4091 行原样 + 61 行新增 + 0 修改删除;styles.css 字节级未动;新版本独立目录,旧版完整保留可回滚。

## 系统角色与权限边界

| 角色 | 可以 | 不可以 |
|---|---|---|
| 学生 | 资料修改、AI 聊天、测评、画像、树洞、训练 | 查看他人数据 |
| 家长 | 通过邀请码绑定孩子,看孩子心理趋势/情绪/AI 建议 | 看孩子聊天记录/树洞/私密记录 |
| 学校管理员 | 本校匿名聚合统计(学生数/测评数/趋势/主要压力来源) | 查看具体学生聊天与私人表达 |
| 社区管理员 | 区域汇总(覆盖学校/服务人数/心理需求趋势) | 查看学校内部明细 |

## 数据表(9 张)

users、schools、ai_personality、chat_records、assessments、emotion_records、family_bindings、tree_hole、user_behavior —— 字段、索引、外键与 RLS 策略见 `database/migrate.sql`。

## 合规边界

- AI 输出不构成医学或心理诊断,不替代专业咨询;
- 高风险检测仅提示「建议寻求专业帮助」并附 12356 热线;
- 演示数据全部虚构脱敏,不接入真实学校/社区生产数据;
- 量表版权(PHQ-9/GAD-7/PSS-10/ISI/RSES)用于研究与教育用途,平台标注出处。
