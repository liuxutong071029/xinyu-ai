# 项目交接说明(心屿 MindIsle v3.0)

## 一、这份包里有什么

| 目录 | 内容 | 接手人需要做什么 |
|---|---|---|
| frontend/ | 前端 5 个静态文件(index.html / styles.css / app.js / themes.css / favicon.svg) | 双击 index.html 即可打开;部署时整目录上传 |
| server/ | 零依赖 Node API(入口 index.js + 7 个路由 + 8 个 lib + 冒烟脚本 + 种子脚本) | `cd server && node index.js` 直接跑,不需要 npm install |
| database/migrate.sql | Supabase 迁移脚本(9 表 + 15 条 RLS + 演示种子) | 可选:在 Supabase SQL Editor 执行即完成建库 |
| docs/ | 项目介绍/部署运行/测试账号/验收说明/API 文档/权限验证/部署回滚手册/验收总览.html | 答辩与演示直接用 |

## 二、接手人 5 分钟上手

1. 双击 `frontend/index.html` → 登录页点任一演示账号(密码 demo123456)→ 右上角 🎨 切 12 套风格;
2. 想跑后端:`cd server && node index.js`(纯 API);要同时托管前端页面,Windows PowerShell 下先 `$env:STATIC_DIR="../frontend"` 再启动 → 浏览器开 http://127.0.0.1:3001/ → 另开终端 `node scripts/smoke.js` 应输出 31 通过/0 失败;
3. 想接真数据库:supabase.com 建免费项目 → SQL Editor 执行 `database/migrate.sql` → 带 `SUPABASE_URL`/`SUPABASE_SERVICE_KEY` 重启;
4. 想接真大模型:带 `AI_API_KEY`(OpenAI 兼容)重启;不配就用内置规则回复。

## 三、技术要点(维护者必读)

- **主题系统**(v3.0 唯一新增的前端代码):`frontend/themes.css`(12 主题块,只在 `body[data-theme="xxx"]` 作用域生效)+ `app.js` 中 `THEMES` 常量与 `isThemeEligible/applyTheme/openThemePanel/pickTheme` 四个函数 + 6 处挂钩点(afterLogin/init/logout/saveIdentityModal/renderUserArea/ensureDemoAccounts)。主题资格 = 初中/高中学生 + 演示账号;**改主题千万不要动 styles.css 和任何 primary-*/kid-* 类(小学界面)**。
- **缓存**:index.html 里三个资源带 `?v=3.0.0`;每次改完前端记得 bump 版本号,否则老浏览器吃旧缓存。
- **数据**:前端全部存 localStorage(键前缀 xinyu-*);后端 mock 模式存 server/data/db.json(已 .gitignore),Supabase 模式存 9 张表。
- **权限**:RLS(15 策略)+ 接口守卫双保险,矩阵见 docs/权限隔离验证记录.md。

## 四、上传 GitHub 清单(照做即安全)

1. 仓库根目录直接放本包内容(或推整个 MindIsle-v3 目录);
2. `.gitignore` 已排除:server/data/(密钥与本地数据)、*.log、.env、node_modules、压缩包、截图证据目录;
3. 安全核验结论:包内无真实 API Key、无数据库连接串、无真实个人信息(已由独立检查 Agent 逐文件核验);
4. GitHub Pages 发布:新建 `v3/` 目录放 frontend/ 内容,旧版文件不动 → 新旧并存,可随时回滚。

## 五、已知边界(非 bug)
