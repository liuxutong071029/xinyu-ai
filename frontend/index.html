核心理念：让心理健康支持触手可及，让每一个人都拥有被倾听的机会。

红旅定位：面向心理资源薄弱地区，构建「学生—学校—家庭—专业资源」四方协同体系，推动心理资源下沉、弥合城乡差距。

商业模式：① 创意验证期免费测试 → ② 高校采购（平台 + 心理教育 + 数据分析）→ ③ 公益与政府合作（乡村学校 / 青少年项目）。

未来规划：MVP 100-500 名真实用户 → 心理专业指导体系 → 1-3 所高校试点 → 覆盖高校 / 中小学 / 基层教育机构。

特色方向：心屿心理树洞终端（规划）——面向乡村 / 寄宿 / 基层学校的智能终端：匿名表达 → AI 分析 → 心理支持 → 连接专业资源，实现线上平台 + 线下场景融合。

🛡️ 为什么是「分级干预」而不是「又一个聊天机器人」

心屿遵循国际主流的分级干预模式（Stepped Care）：测评 + AI 对话 → 分层。轻度问题交给 AI 疏导与自助训练；中重度问题建议转介学校心理咨询中心或专业机构。AI 不替代专业咨询师，而是让有限的心理健康资源用在最需要的人身上。所有量表均采用国际通用的标准化工具，带参考文献与使用说明。
